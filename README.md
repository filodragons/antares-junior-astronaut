# Antares Junior Astronaut

Build a Mars colony simulation web application. Using the exact uploaded reference image as the primary visual design baseline, style the main landing page with the exact same deep red space aesthetic, color palette, and premium vibe.

Specific requirements for the landing page:

1 Site Name: The entire website is named "ANTARES" (replacing "SpaceWeb" from the reference image).

2 Main Title & Subtitle: At the top/center, display the main title "Mars Colony Junior Commander", and right below it, display the exact official challenge name: "build a junior astronaut mission trainer”

3 Interactive Field: In place of the "Explore Now" button from the reference image, create a sleek, futuristic text input box where the user can type and enter their name, followed by an action button to enter the colony.

4 Visual Execution: Keep the layout tight, elegant, and high-end, maintaining the exact atmospheric deep red glow, typography, and structure of the reference image.
